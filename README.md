# ☕ Coffee Blooms Homestay Website

A premium, responsive website designed for **Coffee Blooms Homestay**, showcasing a calm and luxurious stay experience with easy booking access.

---

## 🌿 About the Project

This website is built to help Coffee Blooms Homestay attract guests by presenting:
- A clean, modern design
- High-quality visual gallery
- Quick booking via Call & WhatsApp
- Mobile-friendly layout

The design focuses on **comfort, trust, and ambience**, matching the homestay’s peaceful environment.

---

## 🚀 Features

- Fully responsive design (mobile, tablet, desktop)
- Premium dark theme with glassmorphism elements
- Floating WhatsApp booking button
- Image gallery showcasing rooms and ambience
- Direct call and WhatsApp booking options
- Google Maps location link
- Fast loading & SEO-friendly structure

---

## 🛠️ Tech Stack

- HTML5  
- CSS3 (Modern layout & animations)  
- JavaScript (Light interactions)  

No frameworks used — clean and lightweight.
